# Changelog

## 2.0.1 — 2026-11-22

- The installer now asks whether to install for everyone on the computer or only for you; an update keeps the mode and folder of the existing install
- "Only me" installs need no administrator prompt
- The media view now follows the project's folder when you edit it or switch project, instead of listing the old folder and reporting "No audio files found"
- A card's border, shadow and dimmed look no longer stay behind after a drag ends
- The character counters on the card dialog and the drop zone's colours no longer keep a stale red or drag colour
- The stored-paths setting (Absolute / Relative) now sits on one row, with the explanation on the left and the buttons sized to their text
